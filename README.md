# Tools for agentic coding

## Zed editor

- best in class, very very fast
- integrated agent
- remote coding via SSH
- parallel agents, debugger, native git suppor, etc, etc

https://zed.dev/

## AI harness / coding agents

### Zed agent

- directly integrated to Zed, treesitter, debugger
- easy integration with existing inference providers (eg OpenAI, Anthropic, OpenRouter)
- provide a inference via subscription

https://zed.dev/pricing

### OpenCode

- open source AI coding agent
- free models included or connect any model from any provider, including Claude, GPT, Gemini and more.

https://opencode.ai/

## Plugins + skills

Use tokens more efficiently

see ```skills/``` folder for a collection of currated skills.

### Superpowers

Superpowers is a complete software development methodology for your coding agents, built on top of a set of composable skills and some initial instructions that make sure your agent uses them.

https://github.com/obra/superpowers

### Ponytail

You know him. Long ponytail. Oval glasses. Has been at the company longer than the version control. You show him fifty lines; he looks at them, says nothing, and replaces them with one.

https://github.com/DietrichGebert/ponytail

## Inference providers

### OpenRouter

- no subscription
- per usage pricing, can use cheap free models (might not be ideal for huge batch jobs)
- auto-router feature (use the cheapest avail model)

https://openrouter.ai/
